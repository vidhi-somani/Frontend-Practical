# Multiple-Choice Quiz

A simple 4-question JavaScript quiz built with plain HTML, CSS and JavaScript.

## Features
- 4 beginner-level JavaScript questions stored in an array of objects
  (question text, four options, index of the correct answer)
- One question at a time, answered with radio buttons
- Counter in the format "Question X of Y"
- Next button stays disabled until an option is selected
- Button text changes to "Finish" on the last question
- Score increases for every correct answer
- Result screen shows score (e.g. 3/4), percentage and feedback:
  - 100% - "Excellent work!"
  - 50% or more - "Good job!"
  - Below 50% - "Keep practising!"
- Restart Quiz button starts again from the beginning

## How to run
1. Download or clone the repository.
2. Open the `Multiple-Choice-Quiz` folder.
3. Double-click `index.html` to open it in any web browser. No installation needed.

## Files
- `index.html` - page structure
- `style.css` - styling
- `script.js` - quiz logic
