# Shopping Cart with Discount

A simple shopping cart built with plain HTML, CSS and JavaScript.

## Features
- Cart items stored in an array of objects (`name`, `price`, `quantity`)
- Starts with Notebook (Rs. 120), Pen Pack (Rs. 60), Water Bottle (Rs. 350), quantity 1 each
- Table with Item, Price, Quantity, Total and Remove columns
- `+` and `-` buttons change the quantity (it never goes below 1)
- Remove button deletes the item from the cart
- Subtotal updates automatically
- 10% discount when subtotal is Rs. 1000 or more
- Shows subtotal, discount amount and final payable amount
- Shows "Your cart is empty." when all items are removed

## How to run
1. Download or clone the repository.
2. Open the `Shopping-Cart-with-Discount` folder.
3. Double-click `index.html` to open it in any web browser. No installation needed.

## Files
- `index.html` - page structure
- `style.css` - styling
- `script.js` - cart logic
